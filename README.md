# TBTX Static Ecosystem Prototypes

This is the production-ready, static HTML/CSS version of the TransformBy10X (TBTX), BizBuilders AI (BBAI), and BizBot Marketing (BBM) ecosystem.

## Project Structure
- `transformby10x/`: Philosphy / Hard Cuts manifesto.
- `bizbuilders/`: Infrastructure / System Reveal editorial.
- `bizbotmarketing/`: Live Diagnosis surface with functional 15-question engine.
- `styles.css`: Central "Swiss Industrial Paint" design system.

## Features
- **Functional Diagnostic**: A complete 15-question intake engine implemented in Vanilla JavaScript (`bizbotmarketing/index.html`).
- **Archetype Scoring**: Calculates weights for Tool Overload, Bottleneck, Fragmentation, and Stall.
- **Dynamic Results**: A separate `blueprint.html` that renders high-end diagnostic reports based on the intake results.

## Hosting & Review
Since this is a static project, it can be hosted anywhere:
- **GitHub Pages**: Simply enable in repository settings.
- **Local Server**: Run `python3 -m http.server` in the root and view at port 8000.
- **Vercel/Netlify**: Deploy as a static site by pushing the repository.
